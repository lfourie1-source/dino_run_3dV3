# Analytical Reflection

Generative AI was useful during this project because it made it possible to prototype and revise game systems quickly. I used AI-assisted coding to create the browser game structure, player movement, jumping, procedural obstacles, collision detection, scoring, high scores, coins, dimension changes, responsive controls, and audio events. The strongest benefit was iteration speed: I could describe a gameplay problem, test the new build, and then immediately refine the mechanic.

The process also showed why AI output cannot be accepted without human testing. Several generated versions looked complete but contained important problems. The A and D controls were reversed more than once, early obstacle generators created “safe lanes” where the player could gain points without doing anything, and oversized single-file HTML exports with embedded audio were unreliable. I caught these issues by repeatedly playing the game and giving specific correction prompts. The safe-lane problem was especially useful because random obstacle placement sounded correct in theory but still failed in actual play. The final solution used mandatory full-width jump hurdles instead of relying only on randomness.

Human creative curation shaped the final game. I chose the third-person dinosaur concept, blocky arcade art direction, monochrome first dimension, color desert second dimension, void third dimension, sound choices, coin reward, difficulty curve, and the rule that biome changes happen every 500 points. AI accelerated implementation, but testing, taste, and final design decisions remained human responsibilities.
